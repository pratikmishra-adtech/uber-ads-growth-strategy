# Uber Ads Growth Strategy

Deployment-ready Vite + React project.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production check

```bash
npm run build
npm run preview
```

The production build is written to `dist`.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New > Project** and import the repository.
3. Vercel should detect Vite automatically.
4. Deploy with build command `npm run build` and output directory `dist`.

## Notes

- Forecasts and allocation percentages on the site are illustrative strategy assumptions, not official Uber forecasts.
- The project intentionally removes the earlier India map canvas and uses a cleaner market-prioritisation timeline and card layout.
